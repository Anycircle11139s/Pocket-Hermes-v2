# Pocket-Hermes-v2
I created a custom device which senses and displays the temperature. It is powered by a xiao esp32-s3, so it can connect to wifi/bluetooth. This can be used to fetch apis like time or bus times. I added a rotary encoder for navigation and designed it to be as compact as possible. I made the PCB black with slick af silkscreen and it is powered by a small lipo battery.

BOM: 
<br>

128 x 64 OLED display
<br>

EC11 Rotary Encoder
<br>

4.7k resistors (3)
<br>

3.7v Lipo Battery
<br>

XIAO ESP32 S3 Microcontroller
<br>

PCB
<br>

Assembly instructions:
<br>
Start by soldering all the components onto the pcb (microcontroller, OLED dislpay, temperature sensor, etc)
<br>
Next, solder the Lipo battery to the microcontroller and carefully place it in the case's slot. 
<br>
After that, screw the lid down with the m2 screws.
3D printed case from Printing Legion<br>
